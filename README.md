# Stellar Limitless · 星尘无界

这是一个**无界学习场**：用很小的、能打开就能玩的演示，把「前沿技术」变成你可以摸到的零件。作者在从地质工程转向 IT / AI / 独立游戏，所以每一站都要求——

- 打开就能懂（不是先装一小时环境）
- 改完立刻看见结果
- 技术是真的（程序化生成、可替换的语言模型、受约束的主持人），不是 PPT 名词

当前可玩：**Demo 2 · 火把视野 + 本地地下城主持人**（叠在 Demo 1 的可播种地牢之上）。

## 30 秒怎么玩

1. 用浏览器打开 `index.html`（见下面「怎么运行」）。
2. 地牢默认是黑的。亮点是你；火把只能看清附近一圈。走过的路留下昏暗记忆；没去过的地方纯黑。金色菱形是拾获；紫色圈是异兆；金色台阶是入口，青色台阶是下行。
3. 用 <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> 或方向键走动。左上角有 **HP**（开局 10）。走进新房间会出叙事；踩上异兆可能治疗、受伤或换一件背包物品——数字由主持人表决定，右侧手记只写感觉。
4. 找到青色阶梯后按 <kbd>Enter</kbd> 再下一层。HP 归零则本局结束，点「重生此地」或「换一颗种子」。
5. 默认叙事来自**本地规则引擎**（模板 + 词库），不需要密钥、不需要联网。主持人同样默认离线。
6. 改顶部的**种子**，点「重生此地」：同一种子必得同一张图（迷雾和 HP 是这一局的运行时状态，不改变布局）。点「火把视野 / 全图（学习）」或按 <kbd>F</kbd> 可暂时看全图，用来对照生成结果。

这就是一个完整的短循环：生成 → 摸黑探索 → 读手记 → 管理 HP → 换种子再来。

## 怎么运行

不需要 Node、不需要 `npm install`、没有打包器。

**方式 A（最简单）**

用浏览器直接打开本目录里的 `index.html`。

- Windows：资源管理器中双击该文件。
- macOS：Finder 中双击，或拖到 Chrome / Safari / Firefox 图标上。

正常的话，你会立刻看到深色界面和一团被火把照亮的地牢（四周是黑的），右侧已有一段开场手记。若画布是全黑、也没有房间计数，换一个浏览器再试（建议 Chrome 或 Firefox 近期版本）。想确认地图没坏：点「全图（学习）」，应能看到完整房间轮廓。

**方式 B（本地静态服务器，可选）**

有的浏览器对 `file://` 较严。若方式 A 异常，在本目录打开终端：

```bash
python3 -m http.server 8000
```

终端里应出现 `Serving HTTP on ... port 8000`。然后用浏览器打开：

[http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 探索循环（学什么 → 改什么 → 再开一局）

1. **先当玩家**：摸黑走完一层，踩几格异兆，看 HP 怎么变。问问自己：看不见全图时，你还敢不敢进那条黑走廊。
2. **读笔记**（给零基础、但讲对技术）：
   - [notes/01-pcg-dungeon.md](notes/01-pcg-dungeon.md) — 地牢为什么能「长」出来，种子为什么比 `Math.random()` 重要。
   - [notes/02-llm-adapter.md](notes/02-llm-adapter.md) — 游戏如何同时支持「假 AI」和「真 LLM」，密钥为什么不能进仓库。
   - [notes/03-fov.md](notes/03-fov.md) — 为什么不该看见整张图；半径管距离，阴影管遮挡。
   - [notes/04-gm-state.md](notes/04-gm-state.md) — 主持人如何按状态挑事件；为什么模型不准发明伤害数字。
3. **拧一个旋钮**：打开 `js/fov.js`，只改 `RADIUS`。保存，回到浏览器刷新，用**同一颗种子**重生，对比能看多远。或打开 `js/dungeon.js`，改 `MAX_DEPTH` / `MIN_LEAF`，对照轮廓（布局仍由种子决定）。
4. **（可选）接真模型**：切到 HTTP API，填 Base URL / 模型 / 密钥，保存。再进一间房或踩一格异兆。模型可以在给定选项里挑事件，但不会改 HP 数字。失败时手记会标「本地回退」，游戏继续可玩。

## 文件地图

| 文件 | 干什么 |
|---|---|
| `index.html` | 页面骨架。普通 `<script>` 标签，保证 `file://` 能开。 |
| `css/style.css` | 暗色地牢界面。 |
| `js/rng.js` | 可播种随机数。 |
| `js/dungeon.js` | BSP 切房间、挖走廊、放入口与事件格。 |
| `js/fov.js` | 火把半径 + 视线遮挡；战争迷雾。 |
| `js/llm.js` | 叙事适配器：本地规则 / OpenAI 兼容 API。 |
| `js/gm.js` | 本地地下城主持人：按状态从约束表挑异兆。 |
| `js/events.js` | 走进房间、拾获、异兆 → 先裁决再请求文本。 |
| `js/game.js` | 键盘、画布、按钮、迷雾绘制。 |
| `notes/` | 给探索者的概念笔记。 |
| `LICENSE` | MIT。 |

## 两站分别证明了什么

1. **Demo 1**：种子 + BSP 房间 + 可替换叙事。同一种子，同一张图。
2. **Demo 2**：信息隐藏（FOV）+ 状态反馈（HP）+ 受约束的主持人。AI 从文案机变成「先挑事件、再写句子」。
