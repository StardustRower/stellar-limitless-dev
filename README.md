# Stellar Limitless · 星尘无界

这是一个**无界学习场**：用很小的、能打开就能玩的演示，把「前沿技术」变成你可以摸到的零件。作者在从地质工程转向 IT / AI / 独立游戏，所以每一站都要求——

- 打开就能懂（不是先装一小时环境）
- 改完立刻看见结果
- 技术是真的（程序化生成、可替换的语言模型、受约束的主持人、有限状态的对话、受约束的记忆），不是 PPT 名词

当前可玩：**Demo 4 · 测绘员的旗标账本**（叠在 Demo 1 的可播种地牢、Demo 2 的火把视野与主持人、Demo 3 的对话状态机之上）。

## 30 秒怎么玩

1. 用浏览器打开 `index.html`（见下面「怎么运行」）。
2. 地牢默认是黑的。亮点是你；火把只能看清附近一圈。走过的路留下昏暗记忆；没去过的地方纯黑。金色菱形是拾获；紫色圈是异兆；金色台阶是入口，青色台阶是下行。**青灰色小人是前任测绘员**，火把照到才看得见。
3. 用 <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> 或方向键走动。左上角有 **HP**（开局 10）。走进新房间会出叙事；踩上异兆可能治疗、受伤或换一件背包物品——数字由主持人表决定，右侧手记只写感觉。
4. **找人说话**：默认种子 `stardust-7` 时，从入口往南走进**哨所**，火把里会出现测绘员「灰岩」。走近（或按 <kbd>E</kbd>）打开对话。点短选项：问候之后只能打听 / 交易 / 警告，不能跳到告别。交易需要测线残页（异兆或拾获里可能出现），用残页换灯油并回血；警告会在地图上标一处危险异兆。问候阶段按 <kbd>Esc</kbd> 可先离开。
5. 找到青色阶梯后按 <kbd>Enter</kbd> 再下一层。HP 归零则本局结束，点「重生此地」或「换一颗种子」。
6. 默认叙事与对话都来自**本地规则引擎**（模板 + 词库），不需要密钥、不需要联网。主持人同样默认离线。
7. **（可选）让他跨层记得旗标**：另开一个极小的 FastAPI 账本（见「Demo 4 · 可选账本」）。左上角会变成「账本 · 记得」。在这一层换过油或听过警告，再下楼，他仍知道这件事——但不会把聊天记录塞给模型。账本没开时写「本局失忆」，游戏照常玩。
8. 改顶部的**种子**，点「重生此地」：同一种子必得同一张图（迷雾、HP、对话进度是这一局的运行时状态，不改变布局）。点「火把视野 / 全图（学习）」或按 <kbd>F</kbd> 可暂时看全图，用来对照生成结果。

这就是一个完整的短循环：生成 → 摸黑探索 → 读手记 → 管理 HP → 与一个人按表说话 → （可选）让旗标活过下一层 → 换种子再来。

## 怎么运行

不需要 Node、不需要 `npm install`、没有打包器。前端仍然是双击就能玩。

**方式 A（最简单）**

用浏览器直接打开本目录里的 `index.html`。

- Windows：资源管理器中双击该文件。
- macOS：Finder 中双击，或拖到 Chrome / Safari / Firefox 图标上。

正常的话，你会立刻看到深色界面和一团被火把照亮的地牢（四周是黑的），右侧已有一段开场手记。若画布是全黑、也没有房间计数，换一个浏览器再试（建议 Chrome 或 Firefox 近期版本）。想确认地图没坏：点「全图（学习）」，应能看到完整房间轮廓；哨所里应有一个青灰色小人。左上角多半是「账本 · 本局失忆」——双击打开时很多浏览器会拦住网页去问本机端口，这和服务器没开是同一结果，**游戏仍然可玩**。

**方式 B（本地静态服务器，可选）**

有的浏览器对 `file://` 较严。若方式 A 异常，在本目录打开终端：

```bash
python3 -m http.server 8000
```

终端里应出现 `Serving HTTP on ... port 8000`。然后用浏览器打开：

[http://127.0.0.1:8000/](http://127.0.0.1:8000/)

这只提供网页。灰岩跨层仍会失忆，除非你再开下面的账本。

## Demo 4 · 可选账本（FastAPI）

HTML **不依赖**这个服务。Demo 1–3 的功能（地牢、视野、HP、主持人、对话状态机）在服务关掉时全部照常。账本只做一件事：记住四个旗标（见过面 / 交易过 / 警告过 / 上次停在哪一态）。没有数据库，没有密钥，关掉终端记忆就没了。

在本目录打开终端，三行：

```bash
python3 -m pip install -r server/requirements.txt
python3 -m uvicorn ledger:app --app-dir server --host 127.0.0.1 --port 8765
```

终端里应出现 `Uvicorn running on http://127.0.0.1:8765`。然后用浏览器打开：

[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

这一次网页和账本是同一个地址，左上角应变为「账本 · 记得」。用种子 `stardust-7` 找到灰岩，用残页换油（或听完警告），走到青色阶梯按 Enter。下一层再谈：交易/警告过的选项应不再出现，问候会像「你下来了」，而不是第一次见面。

若提示找不到 `python3`，试 `python`。若不想装 FastAPI：回到方式 A，双击 `index.html` 即可。

Windows 若 `pip` 被拒绝，不必强行折腾——失忆模式就是为这种情况准备的。

## 探索循环（学什么 → 改什么 → 再开一局）

1. **先当玩家**：摸黑走完一层，踩几格异兆，找到测绘员把三个选项都试一遍（没有残页时交易按钮是灰的——这是表在拒绝，不是模型在即兴）。开着账本再下一层，看他还记不记得。再关掉账本刷新，看他会不会失忆。
2. **读笔记**（给零基础、但讲对技术）：
   - [notes/01-pcg-dungeon.md](notes/01-pcg-dungeon.md) — 地牢为什么能「长」出来，种子为什么比 `Math.random()` 重要。
   - [notes/02-llm-adapter.md](notes/02-llm-adapter.md) — 游戏如何同时支持「假 AI」和「真 LLM」，密钥为什么不能进仓库。
   - [notes/03-fov.md](notes/03-fov.md) — 为什么不该看见整张图；半径管距离，阴影管遮挡。
   - [notes/04-gm-state.md](notes/04-gm-state.md) — 主持人如何按状态挑事件；为什么模型不准发明伤害数字。
   - [notes/05-dialogue-fsm.md](notes/05-dialogue-fsm.md) — 对话为什么是状态机；为什么状态是一张表，不是自由聊天。
   - [notes/06-constrained-memory.md](notes/06-constrained-memory.md) — 记忆为什么是旗标不是作文；客户端 vs 服务器；账本挂了会怎样。
3. **拧一个旋钮**：打开 `js/fov.js`，只改 `RADIUS`。保存，回到浏览器刷新，用**同一颗种子**重生，对比能看多远。或打开 `js/npc.js`，改交易的治疗点数 / 某一跳的 `next`，对照他还会不会答应你没写在表上的事。或打开 `js/memory.js` 看 `lineKey` 如何把 `-down` 剥掉。
4. **（可选）接真模型**：切到 HTTP API，填 Base URL / 模型 / 密钥，保存。再进一间房、踩一格异兆、或与灰岩说话。模型可以写口气，但不能改 HP、不能跳状态、不能发明一段没有旗标的回忆。失败时手记会标「本地回退」，游戏继续可玩。

## 四站分别证明了什么

1. **Demo 1**：种子 + BSP 房间 + 可替换叙事。同一种子，同一张图。
2. **Demo 2**：信息隐藏（FOV）+ 状态反馈（HP）+ 受约束的主持人。AI 从文案机变成「先挑事件、再写句子」。
3. **Demo 3**：同一约束用在对话上。NPC 是一张表，不是聊天窗口；模型只写 2～3 句，不能跳状态、不能发明 HP。
4. **Demo 4**：记忆是第二张约束表。旗标活在可选的本地账本里；模型仍然没有聊天记录。账本挂了就失忆，和 LLM 本地回退同一模式。
