# Stellar Limitless · 星尘无界

这是一个**无界学习场**：用很小的、能打开就能玩的演示，把「前沿技术」变成你可以摸到的零件。作者在从地质工程转向 IT / AI / 独立游戏，所以每一站都要求——

- 打开就能懂（不是先装一小时环境）
- 改完立刻看见结果
- 技术是真的（程序化生成、可替换的语言模型），不是 PPT 名词

第一站：**AI 驱动的 Roguelike 地牢生成器**。

## 30 秒怎么玩

1. 用浏览器打开 `index.html`（见下面「怎么运行」）。
2. 你会看到一张黑石地牢。亮点是你；金色菱形是拾获；紫色圈是异兆；金色台阶是入口，青色台阶是下行。
3. 用 <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> 或方向键走动。走进新房间、踩上异兆或拾获，右侧会出现一段叙事。
4. 默认叙事来自**本地规则引擎**（模板 + 词库），不需要密钥、不需要联网。
5. 改顶部的**种子**，点「重生此地」：同一种子必得同一张图。点「换一颗种子」则开始另一局。

这就是一个完整的短循环：生成 → 探索 → 阅读 → 换种子再来。

## 怎么运行

不需要 Node、不需要 `npm install`、没有打包器。

**方式 A（最简单）**

用浏览器直接打开本目录里的 `index.html`。

- Windows：资源管理器中双击该文件。
- macOS：Finder 中双击，或拖到 Chrome / Safari / Firefox 图标上。

正常的话，你会立刻看到深色界面和一张地牢，右侧已有一段开场手记。若画布是黑的、也没有房间计数，换一个浏览器再试（建议 Chrome 或 Firefox 近期版本）。

**方式 B（本地静态服务器，可选）**

有的浏览器对 `file://` 较严。若方式 A 异常，在本目录打开终端：

```bash
python3 -m http.server 8000
```

终端里应出现 `Serving HTTP on ... port 8000`。然后用浏览器打开：

[http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 探索循环（学什么 → 改什么 → 再开一局）

1. **先当玩家**：走完一层，读完几段手记。问问自己：哪些房间好认，哪些走廊太绕。
2. **读两篇笔记**（给零基础、但讲对技术）：
   - [notes/01-pcg-dungeon.md](notes/01-pcg-dungeon.md) — 地牢为什么能「长」出来，种子为什么比 `Math.random()` 重要。
   - [notes/02-llm-adapter.md](notes/02-llm-adapter.md) — 游戏如何同时支持「假 AI」和「真 LLM」，密钥为什么不能进仓库。
3. **拧一个旋钮**：打开 `js/dungeon.js`，只改 `MAX_DEPTH` 或 `MIN_LEAF` 其中一个数。保存，回到浏览器刷新，用**同一颗种子**重生，对比轮廓。
4. **（可选）接真模型**：切到 HTTP API，填 Base URL / 模型 / 密钥，保存。再进一间房。失败时手记会标「本地回退」，游戏继续可玩。

## 文件地图

| 文件 | 干什么 |
|---|---|
| `index.html` | 页面骨架。普通 `<script>` 标签，保证 `file://` 能开。 |
| `css/style.css` | 暗色地牢界面。 |
| `js/rng.js` | 可播种随机数。 |
| `js/dungeon.js` | BSP 切房间、挖走廊、放入口与事件格。 |
| `js/llm.js` | 叙事适配器：本地规则 / OpenAI 兼容 API。 |
| `js/events.js` | 走进房间、拾获、异兆 → 请求一段文本。 |
| `js/game.js` | 键盘、画布、按钮。 |
| `notes/` | 给探索者的概念笔记。 |
| `LICENSE` | MIT。 |
