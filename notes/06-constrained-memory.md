# 记忆为什么是旗标，不是一篇作文

Demo 3 刚证明：地下城里的人是一张表，不是聊天窗口。留下一个很具体的洞——按 `Enter` 下一层时，游戏会调用 `newRun(种子 + "-down")`。大白话：它把这一局的地图、血量、背包、以及站在哨所里的那个人，全部扔掉，再按新种子长出一张新图。

JavaScript 对象（浏览器里这一次运行时活着的那些数据）跟着被扔掉。灰岩忘了你是否换过油，不是因为他冷酷，是因为**记得这件事的那块内存已经没了**。

这时最容易犯的错，是把右侧手记、或整段对话，塞进下一层给大模型的提示词，然后写一句：「请根据以上聊天记录继续扮演。」模型很会接话。它也会开始发明：你们好像在上一层拥抱过、你好像欠他三壶油、他好像有个死在断层里的徒弟——句子越动人，账越假。

所以这一课只教一件事：**记忆是第二张约束表。** 只准记住表上有的事实，不准记住自由文本。

## 这一张表有多小

只有四个字段：

| 旗标 | 大白话 | 不表示什么 |
|---|---|---|
| `met` | 见过面（打开过对话） | 你们聊了哪些句子 |
| `traded` | 用残页换过灯油 | 油还在不在背包里 |
| `warned` | 听过一次警告 | 上一层被标记的那一格还在不在 |
| `last_state` | 上次对话停在哪一态（问候 / 交易 / 告别……） | 一篇回忆录 |

键是**测线前缀**：种子后面无论叠多少个 `-down`，都算同一条测线。`stardust-7` 和 `stardust-7-down` 是同一个人。点「换一颗种子」才换一条测线。

请把三件事分开，和 Demo 2、Demo 3 是同一张分工图：

| 谁 | 决定什么 | 不决定什么 |
|---|---|---|
| 对话状态机（`js/npc-table.js`，地牢壳 `js/npc.js` / 一幕壳 `js/vn.js`） | 这一层此刻能点哪些选项 | 文笔；跨层记得什么 |
| 账本（`server/ledger.py`） | 这条测线上发生过哪几件事实 | HP、背包、地图、台词 |
| LLM（`js/llm.js`） | 当前状态 + **旗标** 怎么说出口 | 回忆、数字、下一跳 |

默认仍完全离线。账本是可选的，和「要不要接真模型」是同一类旋钮。

## 客户端 vs 服务器

**客户端**就是你正在看的这个网页：`index.html` 加上 `js/` 里的脚本。它负责画地牢、走格子、打开对话。关掉标签页，这一局的 JS 对象就没了。

**服务器**在这一课里小得不像「服务器」：一个 Python 进程，在你自己的电脑上听 `127.0.0.1:8765`（这串是「只给本机看的地址 + 端口」，不是网上的网站）。它手里只有一个字典——一种「名字对应一张小表」的盒子。没有数据库，没有账号，仓库里没有密钥。关掉终端，盒子空了。

为什么现在才需要它？因为旗标必须活过「当前这个网页的内存」，而又**不能**住在模型的上下文里。浏览器的 `localStorage` 也能存四个布尔值；这一课故意不用它当主账本，是为了让你摸到：状态第一次离开页面、跑到另一个进程里，**游戏规则并没有变**。表还是那张表。模型仍然只准写句子。

网页怎么问账本？开始交谈、交易、警告、告别时，试着 GET / POST 那四个字段。成功，灰岩记得。失败，当作没发生过。

## 服务器挂了会怎样

和 LLM 的「本地回退」是同一模式：

- 没装 Python、没运行 uvicorn、浏览器拦住了 `file://` 去 localhost 的请求、账本超时——都算失败。
- 失败时左上角写 **账本 · 本局失忆**。灰岩按这一层刚 `place` 出来的空白旗标说话：没见过你，没换过油。
- 游戏不崩。FOV、HP、主持人、对话状态机都还在。你仍然能走、能谈、能下楼。
- 双击 `index.html` 永远能玩。账本是加分项，不是门票。

反过来，账本开着时：在这一层换了油，走到青色阶梯按 Enter。下一层的灰岩仍站在新地图的哨所里（布局由新种子决定），但交易按钮不会再出现——他记得这件事。警告同理。问候会换成「你下来了」而不是第一次见面。

请注意这**不是整局存档**：下行之后 HP 仍回到 10，背包仍是空的。油壶和伤口按新一局重置。账本只记「这件事发生过」，不记你身上还剩什么。否则你会以为自己在做云存档，而这一课要教的是更窄的东西——**角色记忆的最小合法形状**。

点「重生此地」也不换测线：同一颗种子，账本仍在。想让他彻底忘了，换一颗种子，或把跑账本的那个终端关掉再刷新。

## 为什么绝对不能把聊天记录当记忆

模型没有「这一条测线」的权威账本。你给它三十行对话，它会补上第三十一行它觉得合理的情节。Roguelike 可以残酷，但必须公平：玩家可以骂自己没带残页，不能骂「诗写错了我们的过去」。

旗标够用。见过面、换过油、警告过、停在哪一态——下一层的台词只准围着这四件事说。本地词库按旗标换句式；API 模式把这四个字段写进提示词，并明确告诉模型：**你没有聊天记录，不许发明一句具体的回忆。**

想自己拧：打开 `js/memory.js`，看 `lineKey` 如何剥掉 `-down`。或打开 `server/ledger.py`，看字典里到底只装了什么。保存，开着账本再下一层。你会立刻感到：记得的是规则，不是一篇作文。

Demo 7 让 Godot 的 `HTTPRequest` 去问**同一本**账本，见 [notes/09-godot-ledger.md](09-godot-ledger.md)。客户端换了，四个字段没有换。
