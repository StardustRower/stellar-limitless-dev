# 墙与夜班：三个动词，三个结局

灰岩那一课把「表」搬进了 Godot 的节点树。这一课不再改灰岩。新开一个项目：`godot/wall-npc/`。一面墙，一个夜班，三个动词。数字和结局写在 `wall_table.gd` 里，不写在句子里，更不写在模型里。

## 怎么打开（F5）

仓库里仍然没有 Godot 编辑器、没有导出模板、没有 `.godot/` 缓存。浏览器打不开 `.tscn`。

1. 打开 [https://godotengine.org/download](https://godotengine.org/download)，下载 **Godot 4.x 标准版**（4.2 到 4.7.1 都能开这份文本项目）。不要下 Godot 3；第一天也不要下 .NET 版。
2. 项目管理器点 **Import**，选中 `godot/wall-npc/project.godot`，打开。
3. 按 **F5**，或左上角播放按钮。应出现一间暗色夜班房：左侧是墙（ColorRect + 裂缝），右侧是时刻、耐性、被看见、墙进度，底下三个按钮 **修 / 听 / 说**。
4. 汉字若变成方框：Godot 默认字体几乎不含中文。这一课用 `SystemFont` 去找你电脑上已有的中文字体。仓库里故意不塞一个几兆的字体文件。

`godot/huiyan/` 是另一课，已经冻结。不要为了开这一课去改灰岩的场景或表。

## 三个动词

| 动词 | 对谁 | 表上怎么改数字 |
|---|---|---|
| **修** | 墙 | 时刻 +45，耐性 −5，被看见 +1，墙 +10（上限 97） |
| **听** | 墙 / 系统 / 其他工人 | 时刻 +25，耐性 −3，被看见不变，listen +1 |
| **说** | 墙 / 系统 | 时刻 +20，耐性 −8，被看见 +14，speak +1 |

没有走路，没有地牢，没有第四个日常动词。夜班只准干这三件事。

另外两件事**不是**日常动词，是表在门槛之后才肯亮出来的按钮：

- **抢装备**：耐性 ≤ 28，或被看见 ≥ 55。第四个被禁止的动作。
- **登记罢工**：听满 3 次，并且说满 3 次。系统才肯把拒绝写进班次。

这两个按钮会在 `ExtraOptions` 里被拆掉再重建。拆的时候用 `queue_free`，不用 `free()`——灰岩已经在按钮的 `pressed` 回调里用 `free()` 崩过一次。修 / 听 / 说 是场景里的固定按钮，不拆。

## 为什么墙进度到不了 100

墙进度有上限 **97**。到顶之后，界面写成 **「99. 无法竣工」**。再点修，时刻和耐性仍会走，墙不再加。这不是显示 bug，是表：夜班的墙不准竣工。你可以把 `WALL_CAP` 改成 96 或 90，F5 后进度条会停在新的顶，仍然不会变成 100。

## 夜班时钟

开局 **00:00**，黎明 **06:00**（表上是 360 分钟）。每点一次动词，时刻按上表往前跳。另外，真时间大约 **8 分钟**也会把夜走完——挂机也能到黎明。快速验证请连点，不必等。

黎明是结局条件之一。耐性掉到 0 不会自动结束；它只是把「抢装备」推到台面上。

## 三个结局怎么点（精确路径）

开局固定：时刻 00:00，耐性 72，被看见 4，墙 18。下面三条路都在一次构建里，数字只走 `wall_table.gd` 的 `apply` / `resolve_ending`。

### 1. 修到天明

连点 **修** 八次。

第八下之后：时刻 06:00，耐性 32，被看见 12，墙 97（写成「99. 无法竣工」）。表判定黎明，结局是安静的「你还在」。

### 2. 抢装备世界崩

连点 **说** 四次。第四下之后被看见变成 60，按钮 **抢装备** 出现。再点它。

世界/系统塌掉。这是硬失败，也是冷的笑话。不要先听——听会增加罢工计数，这条路只靠「说」把被看见抬上去。

### 3. 罢工被系统承认

**听** 三次，再 **说** 三次。此时 listen=3、speak=3，被看见 46（还没到抢装备的 55），按钮 **登记罢工** 出现。再点它。

系统写下罢工，并承认。这是手续办完的结局，不是演讲。

点完结局会出字幕和 **重开**。重开回到 00:00，表重新 `make_run()`。
