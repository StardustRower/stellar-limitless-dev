# 第一间 Godot 房：场景是树，表还是那张表

前五站都在浏览器里。这一课第一次打开游戏引擎，只做一件事：让灰岩站进 Godot 的节点树，状态机仍是 `问候 → 打听 / 交易 / 警告 → 告别`。没有走路，没有第二套故事，也不接账本、不接大模型。F5 能玩，就够了。

## 场景和节点是什么（一段话）

Godot 里的一局游戏，不是一篇程序从上往下执行到完，而是一棵**树**：根是这一幕，枝上挂着背景、立绘、对话框、按钮。每一个挂上去的东西叫**节点**（Node）。`ColorRect` 是一块色板，`Polygon2D` 是几个顶点围成的剪影，`Button` 是可点的选项，`Label` 是一行字。它们叠在一起，就是你看见的房间。脚本（`.gd`）挂在某个节点上，用来改数字、换状态、显示下一句。你按 F5，引擎从 `project.godot` 里写好的主场景开始，把这棵树活过来。所以：**场景是这一幕的房间，节点是房间里的家具，表才是灰岩会做什么。**

## 为什么要抄表，而不是重写灰岩

HTML 地牢和 `vn.html` 已经证明：角色是 `js/npc-table.js` 里的状态、选项、下一跳、治疗点数。若在 Godot 里再写一套「好像差不多」的对话，问候也许就能直接告别，灯油也许回 5 点血——两边会悄悄分叉，你不知道哪边才是真的。所以这一课把同一张表抄进 `godot/huiyan/npc_table.gd` 的 Dictionary：同样的 id、同样的边、治疗仍是 3。场景脚本 `huiyan_room.gd` 只是壳，和 `js/vn.js` 同一分工。改表上的 `next` 或 `heal`，应和 HTML 对得上；不要在房间脚本里发明第二套跳转。

引擎换了，故事没有换。这就是 Demo 5 那座桥的另一头。

## 怎么打开（假设你还没有 Godot）

这一课需要 **Godot 4** 编辑器。仓库里没有编辑器、没有导出模板、没有 `.godot/` 缓存；只有可阅读的 `project.godot`、`.tscn`、`.gd`。你本机装一次编辑器，以后各课共用。

1. 打开 [https://godotengine.org/download](https://godotengine.org/download)，选你的系统（Windows / macOS / Linux）。
2. 下载 **Godot 4.x 标准版**（Standard）。不要下 Godot 3；也不要第一天就下 .NET 版——那是给 C# 的，这一课用 GDScript，标准版即可。
3. Windows：解压 zip，双击 `Godot*.exe`，不用安装向导。macOS：把 Godot 拖进「应用程序」；若系统拦住，右键 → 打开。Linux：用官网压缩包往往比发行版仓库的版本新。
4. 编辑器先出现项目管理器。点 **Import**（导入），选中本仓库里的 `godot/huiyan/project.godot`，再打开。也可以把整个 `godot/huiyan/` 文件夹拖进去。
5. 打开后按 **F5**，或左上角播放按钮。应出现一间暗色房间：左侧青灰色剪影，右侧问候和三个选项。没有「直接告别」。开局 HP 7/10，背包有半页测线记录。用残页换油后 HP 应变为 10（7+3，3 写在表上）。点「放下残页」，交易按钮变灰——那是表在拒绝。
6. 汉字若变成方框：Godot 默认字体几乎不含中文。这一课用 `SystemFont` 去找你电脑上已有的中文字体（Windows 常见「微软雅黑」，macOS 常见「苹方」）。仓库里故意不塞一个几兆的字体文件。

HTML 演示没有被这一课替换。双击 `index.html` 或 `vn.html` 仍然能玩。Godot 是第三条入口，同一张表的第三层皮肤。
