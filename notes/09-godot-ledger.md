# 客户端、引擎、服务器：同一本保险

前六站已经把三件事分开过：表决定事实，模型只写口气，账本只记四个旗标。Demo 6 让表站进 Godot 的节点树，但房间还是失忆的——旗标活在这一次运行的 Dictionary 里，关掉 F5 就没了。HTML 地牢若先换过油，Godot 这一幕不知道。

这一课只补上第三层：**让 Godot 去问同一本 FastAPI 旗标账本。** 房间不换，表不换，台词库不换。没有第二套问候/交易/告别。

## 请分开记（三件套第一次同时可见）

| 谁 | 住在哪 | 决定什么 | 不决定什么 |
|---|---|---|---|
| **客户端（节点）** | `huiyan_room.tscn` 里的按钮、标签、剪影，以及挂在树上的 `HTTPRequest` | 怎么画、什么时候开口、何时 GET/POST | 另一套状态；聊天记录 |
| **引擎（表）** | `npc_table.gd` 的 Dictionary，和 `js/npc-table.js` 同一张图 | 状态、选项、下一跳、残页换哪件物品、回几滴血、本地台词 | 记不记得上一层；怎么发 HTTP |
| **服务器（四个旗标）** | `server/ledger.py` 进程内的字典，听 `127.0.0.1:8765` | 这条测线上发生过哪几件事实：`met` / `traded` / `warned` / `last_state` | HP、背包、地图、台词、一篇回忆录 |

客户端是皮肤。引擎是物理。服务器是保险柜——而且是一只极小的保险柜：关掉终端，盒子空了。

`memory.gd` 是这三层之间的胶水，对应网页里的 `js/memory.js`。它知道怎么把种子后面的 `-down` 剥掉，怎么把四个旗标装进 JSON，失败时怎么装作失忆。它**不准**把对话框里的句子塞进请求体。

## 为什么这是和 HTML 同一本保险

HTML 地牢按 Enter 下行时，会扔掉这一局的 JavaScript 对象。灰岩忘事，不是因为他冷酷，是因为记得这件事的那块内存没了。账本把四个旗标放到另一个进程里，所以下一层还能问：「换过油吗？」

Godot 这一幕没有下行。它的「扔掉内存」是另一次：你关掉运行窗口，或 HTML 地牢和 Godot 房间根本不是同一次运行。两边若各记各的，就会出现两个灰岩。测线默认仍是 `stardust-7`。键的规则仍是：后面叠多少个 `-down` 都不换人。所以——

- 账本开着：在 `index.html` 用残页换过油，再 F5 打开这一幕，交易按钮不应再出现。问候走表上的「你下来了 / 油换过」句库，不是房间脚本现编的回忆。
- 账本没开：GET/POST 失败。右上角写 **账本 · 本局失忆**。他按这一幕刚 `make_npc()` 出来的空白旗标说话。剪影、选项、回血 3 点都还在。

这和 LLM 的「本地回退」是同一句话：**约束挂了，游戏继续；不准用更聪明的东西去补。** 模型没有聊天记录。账本也没有聊天记录。Godot 的 HTTPRequest 同样没有聊天记录。

## HTTPRequest 是什么（一段话）

网页用 `fetch` 去问本机端口。Godot 里对等的家具叫 **HTTPRequest**：一个节点，挂在场景树上，负责发出 GET 或 POST，然后把回答交回脚本。你在编辑器里能看见它，和看见 Button、Label 是同一类事——客户端是一棵树，请求也是树上的一个节点，不是藏在表里的魔法。

浏览器有一道叫 CORS 的门卫：网页去问别的端口时，服务器得点头。Godot **不是浏览器**，它直接说话，不看 Origin，也不需要 CORS。本课的账本本来就允许任意来源（给 `file://` 和 `:8000` 用）。它不检查 User-Agent。Godot 默认会带类似 `GodotEngine/4.x` 的牌子，**不必为此改路由、不必加密钥**。

地址请写 `127.0.0.1:8765`，不要写 `localhost`。有的电脑上 `localhost` 会走到 IPv6，而 uvicorn 只听了 IPv4 的 127.0.0.1。

## 怎么运行（先账本，再 F5）

仓库里仍然没有 Godot 编辑器、没有导出模板、没有 `.godot/` 缓存。HTML 仍然双击就能玩。这一课多开一个可选的 Python 进程。

**1. 开账本**（和 Demo 4 相同，三个词：安装、启动、地址）

在仓库根目录打开终端：

```bash
python3 -m pip install -r server/requirements.txt
python3 -m uvicorn ledger:app --app-dir server --host 127.0.0.1 --port 8765
```

终端里应出现 `Uvicorn running on http://127.0.0.1:8765`。用浏览器打开这个地址，左上角应变为「账本 · 记得」。可选：种子 `stardust-7`，在地牢里换过油或听完警告。

**2. 再 F5**

打开已经导入的 `godot/huiyan/` 项目，按 F5。右上角应变为「账本 · 记得」。若你刚在地牢换过油，这一幕不应再出现交易；问候应像「见过面」，句子仍来自 `npc_table.gd` 的 `return_traded` / `return_met` 句库。

**3. 关掉账本再 F5**

在跑 uvicorn 的终端按 `Ctrl+C`，回到 Godot 再按 F5。右上角变为「账本 · 本局失忆」。房间照常：问候、打听、交易、警告。他当作第一次见你。

没有 Python、没有 Godot 以外的新工具。没有数据库。没有密钥。不要导出到 Steam。

## 想自己拧

打开 `godot/huiyan/memory.gd`，看 `line_key` 如何剥掉 `-down`，看 POST 的 JSON 里到底有几个键。或打开 `server/ledger.py`，看字典里只装了什么。保存，开着账本：先在地牢换油，再 F5 这一幕。你会立刻感到：记得的是规则，不是一篇作文；客户端换了，保险柜没有换。
