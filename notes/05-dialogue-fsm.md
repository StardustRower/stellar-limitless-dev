# 对话为什么必须是状态机，不能是自由聊天

Demo 2 刚把语言模型从「文案机」变成「受约束的主持人」：先从有限集合里挑一件事，再写句子，**不准发明 HP**。Demo 3 把同一条约束用在更像「角色」的地方——**说话**。

自由聊天看起来更智能：你打什么，对方回什么。问题是：对方一旦能说任何话，也就能答应任何事。「我给你一把神兵」「你的生命变成 999」「跟我走，我带你出城」。句子好听，游戏碎了。地下城里的人如果想当**角色**而不是聊天窗口，他必须先有一张很小的行为表。

这张表就是**有限状态机**（Finite State Machine，FSM）。大白话：这个人同一时刻只能处于很少几个心情/环节里的一个；每个环节只准做表上写过的几件事；做完之后，表规定他下一站去哪。他不能跳，不是因为他笨，而是因为跳了你就不知道自己在跟谁交易。

## 表决定事实，模型只写口气

请把两件事分开记，和 Demo 2 的 GM / LLM 是同一张分工图：

| 谁 | 决定什么 | 不决定什么 |
|---|---|---|
| 状态表（`js/npc.js` 的 `TABLE`） | 现在是问候、打听、交易还是警告；点了哪一项才准跳到哪；残页换哪件物品、回几滴血；警告要不要在地图上标一格 | 文笔 |
| LLM（`js/llm.js`） | 这个人在**当前状态**里怎么把那一跳说出口 | HP、新物品、下一站去哪 |

默认仍是本地规则引擎：台词来自词库，离线、瞬时。切到 HTTP API 时，模型被明确告知：你就是哨所里的前任测绘员，只能处于当前状态，写 2～3 句，**不许改数字、不许跳状态、不许发明表外的东西**。失败就回退本地，游戏继续可玩。

数字为什么还是不能让模型说？因为交易写着「灯油，治疗 3 点」。模型完全可能写成「你恢复了全部生命」或「油壶里还有 40 升」。旁白可以写暖意爬回小臂；屏幕上方的 HP 条才是裁决。右侧手记的灰色小字会标 `HP 8→10`，那是引擎记账。

## 这一张图长什么样

测绘员名叫**灰岩**，优先站在**哨所**，没有哨所就站**残破圣所**。他是叠加层：地牢生成时不掷骰、不改格子，所以同一颗种子仍是同一张图。火把照到他，你才看得见；走进相邻格子，或按 `E`，对话打开。

状态很少，故意很少：

```
未交谈 → 问候 → 打听 / 交易 / 警告 → … → 告别 → 话已说完
```

从问候出发，你只能点表上的三个选项：打听、交易、警告。没有「直接告别」这一跳——那一跳不在表里，点了也不会发生。打听之后仍可交易或警告，也可以告别；交易和警告各只生效一次。交易需要你真的带着**测线残页**（异兆换物或拾获里可能出现）；没有残页时按钮是灰的，不是模型拒绝你，是表这一栏是空的。

警告会在地图上标一处还没踩过的异兆（走廊优先）。那一格从紫色变成偏暖的标记，以后主持人抽伤害事件时也会略加重——他不是在写恐怖故事，他是在改**世界状态**。这就是「说话必须有后果」：否则对话只是另一段旁白。

## 为什么不用自由聊天，为什么现在还不上服务器

自由聊天把「下一步发生什么」交给模型的联想。联想很会接话，不会记账。Roguelike 可以残酷，但必须公平：玩家骂自己没带残页，不能骂「诗写错了交易」。

这一课也不上 FastAPI（一种很薄的网页服务）。密钥和存档还都在浏览器里；测绘员的记忆还只活在这一局里。先让你摸到「角色 = 一张表」，再把同一张表搬到服务器上，你才能看清：**约束在客户端还是服务器，游戏规则并没有变**。模型仍然只准写句子。

想自己拧：打开 `js/npc.js`，只改 `TABLE` 里某一跳的 `next`，或改交易的治疗点数。保存，刷新，用同一颗种子走近他。你会立刻感到：改的是规则，不是一篇作文。
