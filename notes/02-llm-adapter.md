# LLM 适配器：本地规则 vs 真模型

适配器（adapter）是一种很老的设计想法：**游戏只认一种问法**，底下的引擎可以换。

本演示里，游戏永远只说：

> 「给这段上下文，写一段地牢叙事。」

它不关心文字是模板拼出来的，还是远处一台大模型写的。

## 为什么要分两层

你现在可能还没有 API 密钥，也不该为了打开一个网页去申请云服务。所以默认必须是：

- **本地规则引擎**：浏览器里运行，不联网，几乎瞬时。
- **HTTP API**（可选）：OpenAI 兼容的 `/v1/chat/completions`。填了密钥才走这条路；失败就立刻退回本地，玩家不会对着空白等。

接口长这样（概念上，不是要你背函数名）：

```
describe({ seed, trigger, room, language }) → 一段文本
```

`js/llm.js` 做三件额外的事：

1. **缓存**：同一颗种子 + 同一间房 + 同一种触发，只生成一次。Roguelike 讲究「这个厅就是这个味道」，不要每进一次门换一篇作文。
2. **预取**：你还在当前房间时，提前为附近未访问房间请求文本。API 有延迟时，走进去仍像「早就写好了」。
3. **回退**：网络错误、密钥错误、超时（8 秒），都当本地引擎的输入，而不是死掉。

## 怎么切换

页面上方两个按钮：**本地规则** / **HTTP API**。选择存在浏览器的 `localStorage`（一块只属于这个网站的小仓库），刷新还在。

API 设置面板里三项：

| 字段 | 作用 | 例子 |
|---|---|---|
| Base URL | 服务器地址，不要带最后的斜杠问题——代码会自己收拾 | `https://api.openai.com/v1` |
| Model | 模型名，由服务商规定 | `gpt-4o-mini` |
| API Key | 密钥 | 只打在这个框里 |

兼容同一套协议的还有不少（DeepSeek、Groq、本地的 Ollama `http://localhost:11434/v1` 等）。换服务商通常只改这三项，不用改游戏代码。这就是适配器的好处：游戏规则稳住，模型当插件。

## 提示词草稿（Prompt sketch）

发给真模型的内容很短，故意如此。长提示又贵又不稳定。核心约束：

**系统角色（system）**

- 你在为 roguelike 写旁白。
- 2～4 句。要感官（气味、触感、地质细节），不要 HP、金币这种数值。
- 不要自称 AI。

**用户角色（user）** 只塞结构化字段，例如：

```
seed=stardust-7
trigger=enter_room
room=矿脉厅 / Ore Vein Hall
kind=vein
size=7x5
xy=22,14
carrying=半页测线记录
```

`trigger` 可能是：`start`（开局）、`enter_room`（进房）、`item`（拾获）、`event` / `corridor`（异兆）、`exit`（下行）。

温度（temperature）设在 0.7 左右：要一点文采，但同一 prompt 不要太疯。真正的「可复现」在本地引擎更硬——它用种子派生 RNG 抽词条；云端模型即使温度很低也不能保证逐字相同。

## 本地引擎怎么「假装」有文采

它不是神经网络。它是：**房间类型 + 触发类型 + 词库**。

词库按感官分列：气味、声响、看见什么、身体感觉、战利品、异兆。地质工程师会眼熟一些条目（层理、岩芯、断层），这是故意的：用你已有的世界知识，比空洞的「黑暗的地下城」好记。

组合过程由 RNG 抽签，抽签输入包含种子和坐标，所以：

- 离线可玩，而且有味道。
- 适合对照：先看本地文本，再开 API，体会「规则」和「模型」差在哪——这本身就是这门课要你带走的感觉。

中文 / English / 中英对照是同一套结构换词库，不是两套游戏。

## 安全：密钥为什么不能进仓库

Git 仓库会变成公开历史。密钥一旦被提交，即使用后来的提交删掉，旧历史里还在。别人拿到可以拿你的额度去打模型。

所以规则是：

- 代码里 **没有** 缺省密钥，也没有 `sk-` 开头的字样当示例真值。
- 密钥只进 `localStorage`，存在你这台浏览器。
- 演示仓库保持 MIT、可公开。

本机调试 API 时，用完可以在浏览器开发者工具里清站点数据。不要把填好密钥的截图发到公开地方。

## 失败时你应该看到什么

右侧手记的灰色小字会标来源：`本地规则` / `API` / `缓存` / `本地回退`。若你开了 API 却看到「本地回退」和一句错误摘要（例如 401、缺密钥），先查 Base URL 是否带了 `/v1`、密钥是否贴完整、模型名是否被服务商接受。游戏本身会继续走，这是有意设计：探索不该被网关绑架。
